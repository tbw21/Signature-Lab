# Reference-gate hardware/deployment acceptance addendum
Use the exact frozen candidate and retained complete hardware checklist. This addendum is
not a record of passing physical tests. Use a fresh disposable wallet, never real funds.

1. Record HTML/source hashes, exact signer model/hardware/firmware, firmware authenticity
   evidence, browser/OS and opening mode. Operator labels are not cryptographic attestation.
2. On actual supported desktop/phone, open local HTML and intended secure website mode.
   Measure first startup time; verify wallet appears only after the known-answer gate. Help
   should show48answers; subsequent transactions should not restart the gate. Slow platforms
   must stop accurately if budget exceeded, not be declared malware or silently bypassed.
3. Test both word lengths, all scenarios, same original transactions in individual/guided
   paths, both supported QR formats, long/20-output cases and evidence export. Inspect full
   result bytes independently. A matching result is not a device/firmware safety certificate.
4. Using an separately marked fault-injected copy ONLY, confirm a corrupted expected answer
   produces a terminal startup message with no generated wallet or camera. Never distribute
   that fault copy as a genuine release; the genuine candidate remains byte-frozen.
5. Exercise permission denial/cancel, interruptions, reload/Back/Forward, locks and real
   optical scanning. Save original evidence/scan diagnostics before advancing; previous
   release summaries cannot qualify this candidate. Never weaken signer protections.
6. Qualify fixed-method expectations only after reviewing complete pinned firmware/backend
   code and real responses. Do not assume Passport means Prime or that QR means a specific
   auxiliary-randomness policy. No Taproot support or device auto-profile is claimed here.

Any candidate blocker disqualifies its bytes; fix in a newly identified candidate and restart.
Publisher signing, dependency authentication, outside review/rebuild and user comprehension
remain separate. The startup self-check cannot replace publisher authenticity verification.
