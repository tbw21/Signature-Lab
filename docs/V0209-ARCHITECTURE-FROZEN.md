# v0.20.9-dev — frozen presentation-scoped qualification contract

Date: 2026-10-12. Frozen baseline: v0.20.8-dev (HTML SHA-256 from `EXPECTED-OUTPUT.json`).

## Requirements and acceptance
- Session: dominant count and distinct outcome counts, caveat visible and not called safety score; evidence/action region aligned; genuine empty state; Finish separate, non-automatic and warns that unsaved data is lost.
- Advanced: remove redundant nested visual chrome while preserving three disclosures and all editing fields, controls, status semantics and prompts.
- Support 320, 360, 390, 768, 1024, 1440 CSS px without document horizontal overflow; mobile control wrapping, keyboard focus, text-spacing and 200% zoom simulated where feasible; record what is and isn't tested.
- Preserve `sessionSummary`/`guidedStatus` as sole state producers. No new counters, computed business logic, controller, journal, verifier, parser or capture state. Preserve every `x-*`, `@*`, `:disabled`, IDs and action handler for existing controls; new markup may only reuse existing model data.
- Document all changes since v0.20.3-rc1 in a single cumulative What's New.
- No public deployment, GitHub mutation, publisher signing or claim of fully qualified release.

## Architecture and ownership
- Trusted core: all `src/*.js`, vendor blobs, `build.py`, `sources.json`. Must remain byte-identical to v0.20.8-dev, except release metadata and presentation HTML/CSS.
- Optional modules: camera, QR, evidence generation; remain orthogonal to visual styling.
- Authority: single HTML build generated by `build.py`; `source-lock.json` and `EXPECTED-OUTPUT.json` pin one build. GitHub/website must only distribute separately accepted bytes.
- Browser user privileges: read-only UI, local file/camera explicit only; no additional capabilities.
- Reboot/resume: browser reload resets disposable wallet; old archives remain untouched; no migration, extra release pointer, retry engine or changed failure semantics.
- Explicitly retired: no new components retired; no alternate UI-specific logic introduced.

## Contracts
- inspect: source diff, hashes, DOM/ARIA inventory, screenshots.
- plan: this frozen document.
- apply: page.html + style.css + release.json only.
- verify: syntax, static contract, regression subset, controlled browser matrix, fault cases, build-from-archive and deterministic repack.
- status: documented pass/fail/skip/timeout and qualification grade.
- rollback: reopen v0.20.8-dev with a fresh disposable wallet; never mutate historical bytes.

## Release rules
- A defect disqualifies a candidate; fixes require a new unfrozen dev build and rerun from clean start. Record SHA-256 once handoff bytes are finalized.
- Actual signer hardware, native-origin browser and external review are required separately for public acceptance.
