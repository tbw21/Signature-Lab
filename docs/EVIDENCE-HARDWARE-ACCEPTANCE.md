# Physical/browser addendum: evidence retention and replay
This is a checklist, not a passed acceptance record. Use the exact candidate and retained full checklist.
Never load real wallet words, fund invented addresses, broadcast tests, overwrite a real wallet or weaken safeguards.

1. Record the exact release hashes, device/model/firmware, OS/browser, opening mode and authenticity
   evidence. Operator labels do not attest origin. Verify normal startup on the real supported origin.
2. In Session, enable Keep response evidence in this tab before any imports. Complete one ordinary
   physical signing operation. Save the individual result and the session evidence; reopen both saved
   files and independently replay their public data. Match the original response hashes.
3. Complete a short multi-request sequence. Save session evidence once; verify all recorded responses
   are present and previous response bytes do not change after advancing. Compare individual and bundle
   findings, including PSBT v0/v2 and a supported real reduced response when available.
4. Exercise opt-in after a result: earlier evidence must be explicitly missing. Disable retention after
   results: existing attachments remain and later gaps appear. A summary export is still summaries only.
5. On synthetic labelled fixtures, hit byte/payload limits: previous bytes remain, the failure is visible
   and latched, no eviction occurs and core verification rules do not change. Observe low-memory phones.
6. Stop/deny/interruption-test actual camera acquisition. Optional capture records and signature totals
   remain distinct; no automatic retry/reacquisition is allowed. Past missing attempt records are not
   manufactured. Permission dialogs and optics are not qualified by synthetic streams.
7. Save diagnostics with the default setting: no original response, seed, private key, raw frames or
   untrusted exception text is added. Explicitly include current evidence only when intended; inspect
   before sharing. Human notes and returned data are untrusted. Nothing uploads automatically.
8. Before replacing a used wallet, save session evidence from the confirmation. Cancel preserves all
   data. Confirm/reload clears retention and opt-in state. An OS save failure must not be misrepresented
   as successful retention; physically open the downloaded file to check it.
9. Run tests/origins.py in a permitted environment with each installed supported engine, and perform real
   Safari/mobile acceptance separately. --require-all rejects an incomplete advertised matrix.

Initial operation count is a workflow check, not a malware-detection probability. Stop on a blocker,
record evidence and require a new candidate/full qualification for changed bytes. Publisher signing,
component provenance, independent review and unresolved Foundation evidence remain separate gates.
